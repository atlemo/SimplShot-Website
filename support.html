Support

Report a Bug or Request a Feature

The best way to report bugs or suggest improvements is via GitHub Issues. It helps track requests, lets others add context, and makes it easy to follow up.

Open an issue on GitHub →

When reporting a bug, please include:

  • macOS version and SimplShot version
  • Steps to reproduce the issue
  • What you expected to happen vs. what actually happened
  • A screenshot or screen recording if relevant

Contact by Email

For questions that don't fit GitHub — licensing, general feedback, or anything else — you can reach out directly at support@simplshot.com.

Response times may vary, but every message is read.

Common Issues

  • Screen recording not working — Go to System Settings → Privacy & Security → Screen Recording and make sure SimplShot is enabled.
  • Accessibility features not working — Go to System Settings → Privacy & Security → Accessibility and enable SimplShot.
  • Screenshots not saving — Check that SimplShot has permission to access the folder you've selected as your save location.
